# Personas — una nota por persona del equipo

Quién sabe de qué, quién está libre y qué hacía cada quien. Lo escriben y leen
`personas-append.js` y `personas-query.js` (skill `personas`, comando `/quien`).
Formato de ficha: `_ejemplo.md`. Diccionario de frentes válidos: `_dominios.md`.
Los archivos que empiezan por `_` no se cuentan como personas.

**Son datos sobre personas reales:** solo hechos de trabajo con fuente y fecha; jamás salud, vida
privada ni creencias. Los hechos se cierran con fecha (`hasta`), no se borran. Esta carpeta no se
versiona ni se publica (el `.gitignore` sembrado la deja fuera).
